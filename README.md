## 创作原则

1. **小人物视角**：普通工人、家属、基层干部
2. **真实细节**：数据、物价、引语均有来源
3. **地域差异**：东北重灾区 vs 上海广东
4. **时代氛围**：灰色调、寒冷、压抑但有一丝韧性

## 时间范围

核心期：1997-2002年
可延伸：1995-2005年

## 数据红线

- 下岗人数：6000万+（1995-2002）
- 沈阳铁西区：约40万人下岗
- 抚顺下岗率：43%（2001年）
- 长春三轮车夫下岗比例：89%
